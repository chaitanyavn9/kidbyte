01 — The Atom of Memory

What is a Flip-Flop?

A flip-flop is the smallest memory circuit that exists. It stores exactly one bit — a 0 or a 1 — and holds that value until you deliberately change it.

🔵 One Flip-Flop = One Bit

Click the cell below to flip it between 0 and 1. That is literally what a flip-flop does inside a CPU — it switches state and holds it:

D FF
How it works: A D flip-flop captures the value at its input (D) on the rising edge of the clock. Between clock edges, the output (Q) holds its value unchanged — that's the memory. The CPU's clock runs at billions of edges per second, but each flip-flop only updates when explicitly told to.

🧱 Why "Flip-Flop"?

The name comes from its behavior: it flips to 1, and can flop back to 0. The first flip-flop circuits were built in 1918 with vacuum tubes — the same fundamental idea inside every modern CPU register today, just 10,000× smaller.

⚡ SRAM — 6 Transistors per Bit

An SRAM cell (like in CPU cache) uses 6 transistors to build one flip-flop — 4 forming a cross-coupled inverter latch, 2 for access control. This is why SRAM is fast but physically large.

Speed: SRAM reads in ~1–5 ns (CPU L1 cache). No refresh needed — holds state as long as powered. Cost: ~6× area of DRAM. That's why L1 cache is only 32–128 KB, not GBs.

🧠 RAX — The 64-Bit Register

The RAX register in an x86-64 CPU is 64 flip-flops in a row. Each bit position represents a power of 2. The total range: 0 to 18,446,744,073,709,551,615 (~18 quintillion).

03 — The 50-Year Register Evolution

What does "64-bit x86-64" mean?

The bit-width of a processor describes how many bits each general-purpose register holds — and therefore the largest number it can process natively in one instruction. It has evolved three times.

📐 The RAX Evolution

The same register has grown with each CPU generation. The names from each era still work today as aliases into the same register:

Backward compatibility: When you write to EAX (32-bit), the top 32 bits of RAX are automatically zero-extended. When you write to AX (16-bit), only those 16 bits change — upper bits are preserved. This design meant old software ran unchanged on each new CPU generation.

🗂️ The x86-64 Register File

An x86-64 CPU has 16 general-purpose 64-bit registers. Each is 64 flip-flops. The register file is a small, super-fast memory bank directly inside the CPU core:

General Purpose

RAX, RBX, RCX, RDX, RSI, RDI, R8–R15. Used for arithmetic, arguments, return values.

Special Purpose

RSP (stack pointer), RBP (base pointer), RIP (instruction pointer — where in the program we are).

04 — Working Memory

Is RAM made of Flip-Flops?

No — and this surprises most people. CPU registers (SRAM cache) use flip-flops. But the RAM sticks in your computer use something far simpler and more compact: capacitors.

⚡ DRAM: 1 Transistor + 1 Capacitor per Bit

Dynamic RAM stores each bit as a tiny electrical charge in a capacitor — like a microscopic rechargeable battery. One transistor acts as a gate to read/write it. That's it: 1T-1C.

The Big Problem: Leakage

Capacitors slowly lose their charge even with no power applied — like a leaky bucket. A "1" bit gradually becomes indistinguishable from a "0" bit in milliseconds.

Solution: The memory controller must REFRESH every row every ~64 milliseconds — re-read and re-write each cell before it forgets. This is why it's called Dynamic RAM.

⏱️ Your 16 GB RAM has ~128 billion cells. The controller refreshes ALL of them every 64 ms, nonstop, while powered.

05 — Permanent Storage

What is an SSD Internally?

SSDs are built from NAND flash memory — a completely different technology from both flip-flops and DRAM. Instead of holding charge in a leaky capacitor, flash traps electrons in an insulated "floating gate" — permanently, without power.

🔬 The Floating Gate Transistor

The core of every SSD cell is a special transistor with an extra conductor sandwiched in its insulating layer. Electrons can be forced into this floating gate and stay there for 10+ years:

Erased = "1": No electrons in the floating gate. The transistor conducts normally — read as 1.
Programmed = "0": Electrons forced in by Fowler-Nordheim tunnelling at ~20V. They block the channel — read as 0.

📦 SLC / MLC / TLC — Bits per Cell

The brilliant trick of modern NAND: multiple charge levels in one cell. Instead of just "charged/not charged", you can store partial charges to represent more than 1 bit:

QLC (4 bits/cell = 16 charge levels) is used in cheap consumer SSDs. SLC (1 bit/cell) is used in enterprise SSDs where endurance matters. More bits per cell = cheaper but fewer write cycles (~100K SLC, ~1K QLC).

🏗️ NAND Architecture

Cells are connected in series (like Christmas lights) in strings of 32–256. Strings share word lines (rows) and bit lines (columns), forming a page (read/write unit) and a block (erase unit):

Write amplification: NAND must erase an entire block (~256 KB) before rewriting even a single bit. The SSD controller's FTL (Flash Translation Layer) manages this complexity — it's why SSDs have a TBW (Terabytes Written) rating and gradually wear out.
